## About CanvasCourt

CanvasCourt is a place for players, travelers, and local basketball scenes to locate outdoor courts all over Italy. An interactive directory ties court positions, region-based browsing, and practical details into a single destination, so planning a pickup game or hunting down a fresh streetball spot takes far less effort.

Beyond the coordinates, the platform draws attention to what makes these spaces visually distinctive: court murals, urban art, and the street culture that surrounds them. Because the interface adapts to desktop, tablet, and phone screens, exploring for your next court works just as well on the move as it does at a desk.

## Features

- Interactive map for exploring outdoor basketball courts.
- Region-based filtering across Italian court listings.
- Dedicated court entries with the details available for each location.
- A submission flow for adding new courts to the shared directory.
- Discovery of courts tied to basketball murals, urban art, and street culture.
- One web experience covering court spaces throughout Italy.
- Layouts that work on desktop, tablet, and mobile devices.
- Community-driven growth through contributed location knowledge.

## Usage

1. Load CanvasCourt in a current web browser.
2. Pan the interactive map to see which outdoor courts are available.
3. Apply the regional filter to focus the directory on one part of Italy.
4. Pick a court to read whatever information is listed for it.
5. Look through entries linked to basketball murals, urban art, and street culture.
6. Submit a suggestion through the court submission workflow when you know a location that belongs in the directory.

## FAQ

### Who is CanvasCourt meant for?

Players, visitors, local communities, and anyone drawn to outdoor courts and street basketball culture in Italy.

### How can I narrow the courts down to one area?

Open the court directory, then use the Italian region filter to concentrate both the map and the listings on the area you care about.

### Is there a way to add a court that is missing?

Yes. The court submission workflow lets you contribute a new outdoor basketball location to the community directory.

### Will it run on a phone or tablet?

Yes. The interface adapts to desktop, tablet, and mobile screen sizes.

### How do I stay current with the project?

Use the hosted build to get the version currently published, or watch the repository for changes and new releases.

### What if the map or listings fail to appear?

Verify your internet connection, reload the page, and try a current browser. If the problem continues, check the repository issue tracker or file a report including your device and browser details.
